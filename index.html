Status → bucket rules

How each platform's status text is treated. Delivered = closed/received, Cancelled, Expired = platform says expired, Live = still running (becomes Expired automatically when its expiry date is before the as-on date, otherwise Open). Change a dropdown if a status is treated wrongly.

Location → City mapping

Amazon gives a warehouse code and Zepto a warehouse name instead of a city. Type the city you want against each code — it is remembered in this browser. Blinkit/Swiggy cities are auto-cleaned (e.g. Bangalore → Bengaluru, Gurgaon/Noida/Delhi → NCR) and can also be changed here. Rows highlighted yellow have no city yet.
